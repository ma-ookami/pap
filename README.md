# PaP 公開手順(GitHub Pages + Firebase)

PCとスマホをペアにして、コピーした文字・見ているページ・写真・ファイルを受け渡す、自分専用の箱です。
ふだんは **QRコードを読み取るだけ** でつながり、必要なら **Google アカウントで守る** こともできます。
所要時間は20分くらい。費用はかかりません(どちらも無料枠で使えます)。
ほかのアプリ(ますせん・ケージバンなど)とは別の Firebase プロジェクトを作ります。

## できること

- **スマホ → PC**:コピーしてから「📋 コピーした内容を送る」を1タップ。写真・ファイルは「📎」から(1つ10MBまで)
- **PC → スマホ**:画面のどこでも `Ctrl+V` で送信。ファイルはドラッグ。ブックマークレット「➤ PaPに送る」で、見ているページ(URL+選んだ文字)を1クリックで送信
- **届いたもの**:開く・コピー・保存・QRコード(ログインしていない端末にも渡せる)・📌 とっておき・検索
- **自動で消す**:1日/1週間/1か月/消さない(📌 は残る)。設定は全端末で共通
- **つなぐ**:1台目で「新しくはじめる」→ もう1台でQRを読み取り、端末の名前を決める(またはコード8文字を入力)
- **つながっている端末**:画面上に「📱 1台接続中:まさやのiPhone」のように出る。新しくつながるとお知らせ。知らない端末は「外す」で締め出せる
- **Google で守る(任意)**:オンにすると、QRやコードを見られても、その Google アカウントでログインした端末しか開けない
- **Android**:ホーム画面に追加すると、ほかのアプリの「共有」からPaPに送れる

## このフォルダのファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体(画面の骨組み。下の css・js を読み込む) |
| `css/style.css` | 見た目 |
| `js/base.js` | 定数・状態・端末の名前・日付・小さな道具 |
| `js/pair.js` | ペア(つなぐ・コード・QR・Google で守る・作り直す) |
| `js/files.js` | 写真の縮小・ファイルの分割・クリップボード・保存 |
| `js/data.js` | リアルタイム更新・送る・消す・📌・自動で消す |
| `js/render.js` | 画面の描画・QRコード |
| `js/events.js` | 送る・貼り付け・ドラッグ・ボタン・設定 |
| `js/boot.js` | Firebase との接続・起動時のペア選び・新しい版の確認 |
| `firebase-config.js` | Firebase の設定(手順4で貼り付ける) |
| `firestore.rules` | データを守るルール(手順3で貼り付ける) |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・色・「共有」の受け取り |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | アイコン |
| `images/` | 確認用の画像(Git にも公開サイトにも入らない) |

GitHub にアップロードが必要なのは、`index.html`・`css` フォルダ・`js` フォルダ・`firebase-config.js`・`manifest.webmanifest`・アイコン3つです。

---

## 1. Firebase のプロジェクトを作る

1. https://console.firebase.google.com を開く
2. 「プロジェクトを作成」→ 名前に `pap` などを入れて進む
3. Google アナリティクスは「オフ」にして作成

## 2. ログイン方法をオンにする(匿名 と Google)

1. 左のメニュー「構築」→「Authentication」→「始める」
2. 「Sign-in method」タブ →「匿名」を選び、「有効にする」をオンにして保存(ふだんのQRでつなぐのに使います。操作は不要です)
3. 「新しいプロバイダを追加」→「Google」→「有効にする」をオン、「プロジェクトのサポートメール」に自分のアドレスを選んで保存(「Google で守る」に使います)

## 3. データベースを作ってルールを貼る

1. 「構築」→「Firestore Database」→「データベースを作成」
2. ロケーションは `asia-northeast1 (Tokyo)`
3. 「本番環境モードで開始」で作成
4. 「ルール」タブで、最初の文字をすべて消し、`firestore.rules` の中身を丸ごと貼り付けて「公開」

> ファイル置き場に Firebase Storage は使いません(無料のままでは使えないため)。写真やファイルは小さく分けてデータベースに入れています。

## 4. 設定をコピーする

1. 左上の歯車 →「プロジェクトの設定」→ 下の「マイアプリ」でウェブのマーク `</>`
2. ニックネームに `pap` と入れて「アプリを登録」(Hosting のチェックは不要)
3. 表示された `const firebaseConfig = { ... };` の `{ }` の中身をコピー
4. `firebase-config.js` の `window.FIREBASE_CONFIG = { };` の `{ }` の中に貼り付けて保存

## 5. GitHub で公開する

1. GitHub で「New repository」→ 名前 `pap`、**Public** で作成
2. 上の「アップロードが必要なファイル」をアップロードして「Commit changes」
3. 「Settings」→「Pages」→ Branch を `main` / `(root)` にして「Save」
4. 1〜2分で `https://(ユーザー名).github.io/pap/` が公開されます

## 6. 公開URLを Firebase に登録する

1. 「Authentication」→「設定」タブ →「承認済みドメイン」
2. 「ドメインの追加」で `(ユーザー名).github.io` を追加(新しいプロジェクトなので、ほかのアプリで追加済みでも必要)

## 7. つなぐ

1. **PCで**公開URLを開き、「新しくはじめる」を押す。QRコードと8文字のコードが出ます
2. **スマホのカメラ**でQRを読み取り、開いたページで端末の名前(例:まさやのiPhone)を決めて「この名前でつなぐ」
3. スマホでは Safari / Chrome の「ホーム画面に追加」をしておくと、アプリのように開けます。**iPhone のホーム画面アプリは Safari と別扱い**なので、最初に一度だけ、PCの右上 ⌗ で出したコードを入力してください
4. PCでは、左の「➤ PaPに送る」をブックマークバーへドラッグ
5. 中身を守りたいときは、⚙ →「Google アカウントで守る」。ほかの端末は、次に開いたときに Google でログインすると、また使えます

## うまくいかないとき

| 表示・症状 | よくある原因 |
|---|---|
| 「Firebaseの設定が読み込めませんでした」 | `firebase-config.js` を貼り付けていない/アップロードし忘れ |
| 「このURLは Firebase に登録されていません」 | 手順6の承認済みドメインがまだ |
| 「サーバーにつながりませんでした。…匿名ログイン」 | 手順2の「匿名」がオンになっていない |
| 「Google ログインがオンになっていません」 | 手順2の「Google」がオンになっていない |
| 「データベースにつながりませんでした」 | 手順3のデータベース作成・ルールの「公開」がまだ |
| 「コードが違うか、期限が切れています」 | コードは10分で使えなくなります。相手の ⌗ でもう一度出す |
| 🔒「Google アカウントで守られています」 | 守っているのと同じ Google アカウントでログインする |
| iPhone のホーム画面アプリで Google ログインできない | 一度 Safari でログインしてから開き直す。または ⚙ で保護を外してコードでつなぐ |
| 「コピーした内容を送る」で読み取れない | ブラウザが許可していない。入力欄を長押し →「ペースト」→「送る」 |

**QRやコードを誰かに読まれたとき**:ほかの端末に「○○ がつながりました」と出ます。上の「◯台接続中」→ その端末の「外す」を押せば、新しいQRなしでは二度と入れません。QRは1回使うと消え、10分で期限が切れます。

**念のため全部やり直したいとき**:⚙ →「ペアを作り直す」。鍵が新しくなり、古いQRでは開けなくなります(中身は消えるので、残したいものは先に保存してください)。

## iPhone で、もっと早く送る(任意)

「ショートカット」アプリで、次の2つだけのショートカットを作り、ホーム画面や背面タップに置きます。
1. 「クリップボードを取得」
2. 「URLを開く」:`https://(ユーザー名).github.io/pap/?add=1&text=` の後ろに「クリップボード」の変数(「URLエンコード」アクションを挟む)

実行するとPaPが開き、コピーしていた文字がそのまま送られます。

## アプリを更新するとき

1. 手元で確認:このフォルダで `npx http-server -p 8080 -c-1` を動かし、http://localhost:8080 を開く
2. 変更したファイルを GitHub にアップロード。開いているページは、次に画面に戻ったとき自動で新しい版になります
3. `firestore.rules` を変えたときは、Firebase のルール画面に貼り直して「公開」も必要

## 知っておくこと

- **無料枠の目安**:データは合計1GBまで、1日あたり書き込み2万回・読み込み5万回。ふつうの使い方なら十分です。10MBのファイルは1つで約15回の書き込みです
- **写真は元の画質のまま**送ります(10MBを超える写真と HEIC は、自動で JPEG にして送ります)
- **中を開けるのは、ペアに登録された端末だけです。** 登録には、つながっている端末が出したコード(10分・1回だけ)が必要です。パスワードなど大事なものを入れるなら「Google で守る」をオンにしてください
- 誰でも新しいペアを作れる仕組みなので、公開後に **App Check**(ますせんの README と同じ手順)を設定しておくと、無料枠を荒らされにくくなります
